# musi.mp4

Mini proyecto que simula un reproductor de música web utilizando la API de Deezer y Last.fm.

Permite buscar canciones, seleccionar una pista y reproducir una vista previa de 30 segundos. Además, incluye controles básicos de reproducción y la posibilidad de avanzar hacia canciones recomendadas obtenidas mediante servicios externos de música.

## Características

- 🎵 Búsqueda de canciones mediante la API de Deezer.
- ▶️ Reproductor con vista previa de audio de 30 segundos.
- ⏸️ Controles para pausar y reanudar la reproducción.
- ⏭️ Navegación hacia canciones recomendadas.
- 🔎 Visualización de información de canciones y artistas.
- 🎧 Integración con APIs externas de música.
- 📻 Obtención de información adicional mediante Last.fm.

## Tecnologías

### Frontend

- React
- TypeScript
- CSS / Tailwind CSS
- Vite

### APIs

- Deezer API
- Last.fm API
